10 задач по Python

Возрастающая сложность · только input(), print() и математика до 7 класса

Условия задач

1. Площадь прямоугольника. Пользователь вводит длину и ширину. Выведите площадь.
2. Периметр треугольника. Пользователь вводит три стороны треугольника. Выведите периметр.
3. Площадь круга. Пользователь вводит радиус. Выведите площадь круга (π ≈ 3.14).
4. Объём параллелепипеда. Пользователь вводит длину, ширину и высоту. Выведите объём.
5. Средняя скорость. Пользователь вводит путь (км) и время (ч). Выведите скорость по формуле v = s / t.
6. Проценты от числа. Пользователь вводит число и процент. Выведите результат.
7. Периметр и площадь круга. Пользователь вводит радиус. Выведите длину окружности C = 2πr и площадь S = πr².
8. Перевод часов в секунды. Пользователь вводит часы, минуты и секунды. Выведите общее количество секунд.
9. Сложные проценты. Пользователь вводит вклад P, годовую ставку r (%) и количество лет n. Выведите итоговую сумму по формуле S = P · (1 + r/100)n.
10. Теорема Пифагора. Пользователь вводит два катета. Выведите гипотенузу по формуле c = √(a² + b²).
Бонус. Формула Герона. Пользователь вводит три стороны треугольника. Выведите площадь по формуле Герона.

Прогрессия сложности

ЗадачиЧто тренируется
1–2Простые формулы, сложение/умножение
3–4Использование константы π, три переменные
5–6Деление, проценты
7–8Несколько вычислений в одной задаче
9–10Степень **, квадратный корень ** 0.5
БонусКомбинированная формула
Памятка для ученика
  • input() — ввод с клавиатуры (возвращает строку)
  • float() — преобразование в дробное число
  • int() — преобразование в целое число
  • ** — возведение в степень
  • ** 0.5 — квадратный корень
  • π ≈ 3.14

Можно разбить на два занятия: задачи 1–6 (первое), 7–10 + бонус (второе).

Решения (для учителя)

10 задач по Python · возрастающая сложность

1. Площадь прямоугольника

a = float(input("Длина: "))
b = float(input("Ширина: "))
print("Площадь:", a * b)

2. Периметр треугольника

a = float(input("Сторона 1: "))
b = float(input("Сторона 2: "))
c = float(input("Сторона 3: "))
print("Периметр:", a + b + c)

3. Площадь круга

r = float(input("Радиус: "))
pi = 3.14
print("Площадь круга:", pi * r * r)

4. Объём параллелепипеда

a = float(input("Длина: "))
b = float(input("Ширина: "))
c = float(input("Высота: "))
print("Объём:", a * b * c)

5. Средняя скорость

s = float(input("Путь (км): "))
t = float(input("Время (ч): "))
v = s / t
print("Скорость:", v, "км/ч")

6. Проценты от числа

num = float(input("Число: "))
percent = float(input("Процент: "))
result = num * percent / 100
print(percent, "% от", num, "=", result)

7. Периметр и площадь круга

r = float(input("Радиус: "))
pi = 3.14
C = 2 * pi * r
S = pi * r * r
print("Длина окружности:", C)
print("Площадь круга:", S)

8. Перевод часов в секунды

h = int(input("Часы: "))
m = int(input("Минуты: "))
s = int(input("Секунды: "))
total = h * 3600 + m * 60 + s
print("Всего секунд:", total)

9. Сложные проценты

P = float(input("Вклад: "))
r = float(input("Ставка (%): "))
n = int(input("Лет: "))
S = P * (1 + r / 100) ** n
print("Итоговая сумма:", S)

10. Теорема Пифагора

a = float(input("Катет a: "))
b = float(input("Катет b: "))
c = (a ** 2 + b ** 2) ** 0.5
print("Гипотенуза:", c)

Бонус. Формула Герона

a = float(input("Сторона a: "))
b = float(input("Сторона b: "))
c = float(input("Сторона c: "))
p = (a + b + c) / 2
S = (p * (p - a) * (p - b) * (p - c)) ** 0.5
print("Площадь треугольника:", S)
