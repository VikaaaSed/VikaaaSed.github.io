Часть 2. Знакомство с циклом while

Имя: Дата:

Что такое цикл?

Цикл — это повторение одного и того же действия несколько раз.

Аналогия: «Пока не выучил стих — повторяй». «Пока есть грязная посуда — мой». «Пока не дошёл до школы — иди».

Синтаксис

while условие:
    действие

Как работает:

  1. Проверяется условие.
  2. Если истинно — выполняется тело цикла.
  3. Снова проверяется условие.
  4. Если ложно — цикл завершается.

Пример 1. Счёт до 5

i = 1
while i <= 5:
    print(i)
    i = i + 1

Вывод:

1
2
3
4
5

Разбор по шагам:

  • i = 1 → условие 1 <= 5 истинно → печатаем 1 → i = 2
  • 2 <= 5 истинно → печатаем 2 → i = 3
  • … и так до i = 5
  • 6 <= 5 ложно → цикл закончен

Пример 2. Обратный отсчёт

i = 5
while i >= 1:
    print(i)
    i = i - 1
print("Пуск!")

Вывод:

5
4
3
2
1
Пуск!

Пример 3. «Пока не введён правильный пароль»

password = ""
while password != "дракон":
    password = input("Пароль: ")
print("Проходи!")

Программа будет спрашивать пароль, пока не введут дракон.

Главная ошибка новичка — бесконечный цикл!
Если забыть изменить переменную внутри цикла, он будет повторяться вечно: 
i = 1
while i <= 5:
    print(i)
    # забыли i = i + 1
Всегда меняй переменную внутри цикла!

Чем while отличается от if?

  • if выполняется один раз, если условие истинно.
  • while выполняется снова и снова, пока условие истинно.
