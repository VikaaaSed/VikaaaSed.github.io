Часть 1. Реши сам — эталонные решения

Задача 1. Кот-обжора
a = int(input("Сколько съел Барсик? "))
b = int(input("Сколько съел Шарик? "))
print("Всего сосисок:", a + b)

Ответ: для 4 и 3 → 7.

Типичные ошибки: забыли int() — тогда получится «43».

Задача 2. Пиратский клад
a = int(input("Золотых монет: "))
b = int(input("Серебряных монет: "))
print("Всего монет:", a + b)

Ответ: для 12 и 8 → 20.

Типичные ошибки: перепутали + и *, забыли int().

Задача 3. Робот-пылесос
a = float(input("Длина: "))
b = float(input("Ширина: "))
print("Площадь:", a * b)
print("Периметр:", 2 * (a + b))

Ответ: для 5 и 3 → площадь 15.0, периметр 16.0.

Типичные ошибки: периметр как a + b без удвоения; int вместо float.

Задача 4. Дракон проспал
h = int(input("Часы: "))
m = int(input("Минуты: "))
s = int(input("Секунды: "))
total = h * 3600 + m * 60 + s
print("Всего секунд:", total)

Ответ: для 2, 15, 30 → 8130.

Типичные ошибки: 60 вместо 3600; забыли умножить минуты на 60.

Задача 5. Пицца для гномов
r = float(input("Радиус: "))
pi = 3.14
print("Площадь пиццы:", pi * r * r)

Ответ: для 10 → 314.0.

Типичные ошибки: pi * r * 2 (длина окружности вместо площади); забыли возвести в квадрат.

Задача 6. Космический код
num = input("Двузначное число: ")
print("Сумма цифр:", int(num[0]) + int(num[-1]))

Ответ: для 47 → 11.

Типичные ошибки: int(num) целиком; индекс 1 вместо -1 (сработает только для двузначных).

Примечание: договориться вводить только положительные двузначные числа.

Часть 2. Найди ошибку — что не так и как исправить

Задача 1. Робот и детали
Ошибка: input() возвращает строку, поэтому "3" + "4" даёт "34", а не 7.
Исправление:
a = int(input("Сколько болтов? "))
b = int(input("Сколько гаек? "))
print("Всего деталей:", a + b)
Задача 2. Кот и сметана
Ошибка: вместо умножения стоит сложение.
Исправление:
print("Итого:", price * count)
Задача 3. Дракон и температура
Ошибка: c — строка, умножать строку на число нельзя (получится повторение строки, а потом ошибка).
Исправление:
c = float(input("Градусы Цельсия: "))
f = c * 9 / 5 + 32
print("Фаренгейты:", f)
Задача 4. Гном и средняя оценка
Ошибка: деление выполняется только для c, нужны скобки. При 3, 6, 9 получится 12.0, а не 6.0.
Исправление:
print("Среднее:", (a + b + c) / 3)
Задача 5. Инопланетный код
Ошибка: у двузначного числа нет индекса 2 — будет IndexError. Есть индексы 0 и 1 (или 0 и -1).
Исправление:
print("Сумма цифр:", int(num[0]) + int(num[-1]))
