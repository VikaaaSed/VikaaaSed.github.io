Карточки-шпаргалки: «Экскурсии по Москве»

1. Каркас страницы

<!DOCTYPE html>
<html lang="en">
  <head> ... </head>
  <body> ... </body>
</html>
  • <!DOCTYPE html> — это HTML5
  • <head> — служебная часть (не видна)
  • <body> — всё, что видит пользователь
Язык стоит lang="en", а страница на русском. Правильнее lang="ru".

2. Подключение шрифтов

<link rel="preconnect" href="...">
<link href="...family=Monomakh..." 
      rel="stylesheet">
body {
  font-family: "Monomakh", system-ui;
}
  • <link> в <head> — подключает шрифт из Google Fonts
  • font-family — применяет шрифт к тексту
  • system-ui — запасной шрифт, если основной не загрузится
Без интернета шрифт Monomakh не загрузится — сработает запасной.

3. Шапка сайта <header>

header {
  background-color: #0199e2;
}
h1 {
  color: white;
  text-align: center;
  font-size: 40px;
  margin: 0px;
}
  • #0199e2 — HEX-код цвета (синий)
  • text-align: center — по центру
  • margin: 0 — убирает внешний отступ
Без margin: 0 вокруг заголовка останутся белые поля браузера.

4. Меню <nav> + flex

nav {
  background-color: darkcyan;
  display: flex;
  justify-content: center;
}
  • display: flex — ставит элементы в ряд
  • justify-content: center — выравнивает по центру
  • <nav> — блок навигации
Flex — это «резинка»: без него ссылки шли бы друг под другом.

5. Ссылки в меню

nav a {
  margin: 10px 40px;
  text-decoration: none;
  color: aliceblue;
  font-size: 30px;
}
  • nav a — «ссылки внутри nav»
  • text-decoration: none — убирает подчёркивание
  • margin: 10px 40px — 10px сверху/снизу, 40px слева/справа
Запись margin: 10px 40px — это сокращение для 4 отступов.

6. Контейнер .container

<div class="container">
  <div class="menu"> ... </div>
  <div class="content"> ... </div>
</div>
.container {
  display: flex;
}
  • Класс — оформляет любой тег с этим именем
  • display: flex ставит меню и контент в ряд
В CSS класс пишется с точкой: .container, в HTML — без: class="container".

7. Блок меню .menu

.menu {
  background-color: blueviolet;
  margin: 20px;       /* внешний */
  padding: 20px;      /* внутренний */
  border-radius: 20px;
}
  • margin — отступ снаружи
  • padding — отступ внутри
  • border-radius — скругляет углы
Padding — «поролон» внутри коробки, margin — расстояние между коробками.

8. Список без точек

.menu ul {
  list-style: none;
  padding: 0;
}
.menu li {
  background-color: darkmagenta;
  margin: 10px;
  padding: 10px;
}
  • list-style: none — убирает маркеры
  • padding: 0 — убирает сдвиг списка
  • .menu li — пункты внутри меню
Без padding: 0 список останется сдвинутым вправо.

9. Картинка <img>

<img src="https://..." alt="Фото Кремля">
img {
  height: 500pxe; /* ОШИБКА! */
}
  • src — путь к картинке
  • alt — описание, если картинка не загрузится
  • Правильно: height: 500px;
Здесь опечатка: 500pxe вместо 500px — браузер не поймёт единицу.

10. Текстовый блок .content

<div class="content">
  <h2>Экскурсии по Москве...</h2>
  <p>Москва — это город...</p>
  <img ...>
  <p>Любителям искусства...</p>
</div>
  • <h2> — подзаголовок
  • <p> — абзац
  • Текст + картинка + текст внутри одного блока
У .content нет стилей — он занимает место по содержимому.

11. Подвал <footer>

<footer>
  <p>©2026. Все права защищены</p>
</footer>
  • <footer> — нижний блок страницы
  • © — символ копирайта
В коде у footer нет стилей — он будет серым текстом на белом фоне.

12. Схема страницы

<body>
  <header>   ← шапка
  <nav>      ← меню
  <div class="container">
    <div class="menu">    ← слева
    <div class="content"> ← справа
  </div>
  <footer>   ← подвал
</body>
  • Сверху вниз: шапка → меню → контент → подвал
  • flex ставит menu и content в ряд
Так выглядит типовая структура сайта — запомни её.
